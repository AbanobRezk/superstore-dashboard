# Superstore Sales Analysis Dashboard

An interactive dashboard for analyzing Superstore sales data, tracking business KPIs, and visualizing sales and profitability trends.

## Features
- CSV data upload and exploration.
- Data cleaning and preprocessing.
- KPI tracking: Sales, Profit, and Quantity.
- Interactive charts for categories, regions, and monthly trends.
- Correlation analysis.

## Tech Stack
Python · Pandas · NumPy · Streamlit · Plotly

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
